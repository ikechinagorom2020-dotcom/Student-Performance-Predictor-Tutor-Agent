# Student Performance Predictor & Tutor Agent

## Overview

The **Student Performance Predictor & Tutor Agent** is a Machine Learning and AI project designed to help students understand their academic performance and improve their preparation for exams.

The system predicts a student's likely exam score based on factors such as study time, attendance, previous failures, family support, and other student-related information.

It also provides a personalized study plan and an AI tutor that can ask practice questions, evaluate answers, and track quiz scores during a session.

## Key Features

* 📊 **Score Prediction** – Predicts a student's expected exam score on a 0–20 scale.
* 📚 **Personalized Study Plan** – Generates study recommendations based on the student's results and key factors.
* 🤖 **AI Tutor** – Allows students to interact with an AI tutor.
* 📝 **Practice Quizzes** – Generates questions and evaluates student answers.
* 📈 **Quiz Tracking** – Keeps track of correct and incorrect answers during a session.

## Machine Learning

This project uses **Supervised Machine Learning with Regression** to predict student performance.

The model was trained using the **UCI Student Performance Dataset**.

Feature engineering was also applied to create useful variables such as parental education, support level, alcohol consumption index, and study-time/failure interaction.

## How It Works

**Student Information → ML Model → Predicted Score → Personalized Study Plan → AI Tutor & Practice Quiz**
